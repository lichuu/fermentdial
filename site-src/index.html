Before you start

  • Use a data cable USB-C charge-only cables power the Dial but carry no serial data.
  • Chrome or Edge, on desktop Web Serial isn't available in Firefox or Safari — use the PlatformIO route instead.
  • No serial port listed? Hold the Dial's side button while plugging in USB to enter download mode.
  • Skipped the Wi-Fi step? The device starts an open FermentDial-Setup-XXXX access point — join it and open http://192.168.4.1/.
  • Updating later Future releases install from the dashboard: Settings → System → Check for updates.
